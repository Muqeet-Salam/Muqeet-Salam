## Things I've Built/helped build

### Inferno AI — Document Intelligence

A document intelligence system built around **LayoutLMv3**, capable of document classification and summarization.

`Python • PyTorch • LayoutLMv3 • FastAPI • Streamlit`

🏆 **Finalist — Appian AI Challenge 2025, IIT Madras**

---

### Discord Memory RAG

A semantic memory system built over **60,000+ Discord messages**.

The pipeline ingests conversations, creates contextual chunks, embeds them into a vector database, retrieves relevant history, and uses an LLM to generate grounded responses.

`Python • FastAPI • ChromaDB • Sentence Transformers • Gemini`

---

### COSC HackWeek

A full-stack hackathon management platform supporting **700+ participants** with registrations, submissions, announcements and live leaderboards.

Led a **10-person development team** to build authentication, organizer workflows and real-time communication.

`React • Firebase • Firestore • WebSockets`

---

### GitGallery

A small systems-oriented project that interacts directly with the GitHub API to explore repositories and images.

Built in **C using libcurl**.

`C • libcurl • REST APIs • System Programming`
